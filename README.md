## 🎯 What This Does

This project documents how to recognize and troubleshoot **co-op lobby & connection check** in **Coal Duty**. It focuses on **Friend invites, multiplayer sessions and lobby connection behavior** with targeted checks, patch awareness, and reproducible testing so players can narrow down the actual cause instead of guessing.

## ✨ Features

- Checks whether recent multiplayer lobby fixes are installed for all players.
- Tests invitations with a fresh two-player lobby and alternate hosts.
- Helps isolate networking problems from a lobby/session-specific issue.

## 🔎 Symptoms Covered

- Players receive an invite but cannot join the host.
- A multiplayer lobby opens but breaks before the game starts.
- Clients experience inconsistent behavior after a lobby restart.

## 🛠️ Troubleshooting — Step by Step

1. **Update both sides.** Early patches affected lobby behavior; confirm every player has the latest build.
2. **Recreate the lobby.** Close the previous lobby and start a new private session with only host and one guest.
3. **Switch the host.** Try creating the same lobby from another player’s PC.
4. **Check networking basics.** Confirm both Steam clients are online and that a firewall or VPN is not disrupting the game.
5. **Compare results.** Log which invitation method works, error text and player count.
